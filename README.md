# Sistema de Administración y Reserva de Habitaciones de un Hotel

## Descripción

Sistema integral para la administración y reserva de habitaciones de un hotel o cadena hotelera, desarrollado como proyecto de cátedra.

El sistema está compuesto por un backend en Java con Spring Boot, que expone una API REST siguiendo principios de arquitectura orientada a servicios (SOA), y un frontend en HTML, CSS y JavaScript que consume dicha API. Permite gestionar hoteles y sucursales, habitaciones y tarifas, huéspedes, reservaciones, pagos, cancelaciones, servicios adicionales y reclamos.

El proyecto se desarrolla en dos fases:
- Fase 1: Documento técnico de diseño (estrategia de solución, prototipos de interfaz y diseño de base de datos).
- Fase 2: Implementación completa de la API REST y su integración con el frontend.
